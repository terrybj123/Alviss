# AI 助手

Alviss 内置一个对话面板。它基于你正在阅读的笔记作答，回答边生成边显示，并且直接连接你自己配置的模型服务商。Alviss 不提供 AI 服务，也不代理你的请求。

## 打开对话

按 **⌘⇧K**，或打开命令面板（**⌘K**）选择 **打开聊天**。对话会覆盖在编辑器上方，按 **Esc** 关闭。

首次打开会直接停在服务商页面，因为此时还没有可用的模型。

## 选择服务商

Alviss 不自带模型，你需要指向一个：

| 服务商 | 运行位置 | 密钥 |
|---|---|---|
| OpenAI | 云端 | 需要 |
| Anthropic | 云端 | 需要 |
| DeepSeek | 云端 | 需要 |
| Ollama | 本机 | 不需要 |
| LM Studio | 本机 | 不需要 |
| 自有服务器 | 任意 | 视情况 |

**自有服务器**是通用入口：任何兼容 OpenAI 对话协议的服务都可以。填入名称、地址（例如 `https://your-server/v1`），需要的话再填 token。本机地址可以用明文 `http`，其他地址必须是 `https`。

**测试连接**会向服务商请求模型列表，并显示在模型字段下方，不必凭记忆输入模型 ID。

## 密钥

密钥保存在 macOS 钥匙串，由应用的原生进程在发起请求时读取。它之后不会再显示——面板里没有、设置里没有、日志里也没有——更不会写进你的笔记库。不同服务商可以各自保存密钥。

**移除**会把密钥一并从钥匙串删除。

## 会发送什么

只有回答问题所需的内容：

1. 一段说明助手角色的简短指令。
2. 你正在阅读的笔记——「当前笔记」开启时会附上；切换成「不带笔记」就只发问题。
3. 到目前为止的对话。

过长的笔记会在发送前按固定上限截断。除此之外没有任何东西离开本机：不会上传笔记库目录、文件名或设置。

## 回答

回答边生成边显示，结束后保留在对话中。**停止**会中断生成并保留已经到达的部分。

回答按 Markdown 渲染，且全部转义：模型写出的 HTML 只会显示为文本，不会被当作页面执行。

**新对话**会清空面板。最近一次对话按笔记库分别记住，下次打开时自动恢复。

## 出错时

提示会告诉你该怎么修，而不只是哪里坏了：

| 提示 | 处理方式 |
|---|---|
| 服务商拒绝了密钥 | 打开「服务商」，重新填写密钥 |
| 服务商不认识这个模型 | 检查模型 ID；用「测试连接」列出可用模型 |
| 这个密钥被限流了 | 稍等片刻再试 |
| 笔记和问题超出模型窗口 | 关掉上下文，或换一个窗口更大的模型 |
| 连不上服务商 | 检查地址和网络 |

## 助手不会做什么

它不会写入你的笔记库。它没有工具、没有自己的联网能力，也无法修改文件。要改动笔记，始终由你自己动手。
