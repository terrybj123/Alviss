# The mobile app

Alviss is a macOS application. There is no iPhone, iPad or Android build yet.

The shared code base is written so a phone shell could reuse it — the parity
catalog (`packages/ui/src/lib/featureParity.ts`) records what such a shell would
still need, feature by feature — but nothing is published, and no store listing
belongs to this project.

If you are looking for Plainva's phone apps, they belong to the upstream project
and are not part of Alviss.
